Это тестовый документ для проверки работы AI-ассистента.

Содержание:
1. Введение в проект AIst
2. Основные функции
3. Технологический стек

Проект AIst представляет собой интеллектуального ассистента с поддержкой загрузки файлов различных форматов.

Основные возможности:
- Чат с AI через OpenRouter API
- Загрузка и анализ текстовых файлов
- Поддержка Word документов
- Сохранение истории переписки

Технологии: Next.js, TypeScript, Prisma, PostgreSQL, NextAuth.
